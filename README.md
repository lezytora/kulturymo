# Культуримо

Студентське онлайн-медіа про культуру Львова та області. Кредо: **«Культура ближче, ніж здається»**.

Замки, фоторубрика, Євробачення, кіно, «Культурно пояснюємо», музика «Між нот», неординарні люди та афіша вистав львівських театрів.

**Live-демо:** https://kulturymo.vercel.app

## Стек

- HTML + CSS + vanilla JavaScript (ES-модулі). Без фреймворків, без збірки, без npm-залежностей і без бекенду.
- Шрифти з Google Fonts: Unbounded (заголовки), Inter (інтерфейс), Source Serif 4 (текст статей).
- Деплой — Vercel: Framework Preset **Other**, Build Command і Output Directory порожні.

Увесь контент (матеріали, автори, рубрики, афіша, тексти «Про нас») лежить в одному файлі — **`js/data.js`**. Сторінки рубрик, матеріалів, авторів, афіша й пошук будуються з нього в браузері.

## Як запустити локально

ES-модулі не працюють, якщо просто відкрити `index.html` з диска (`file://`), потрібен локальний сервер:

- **VS Code:** розширення Live Server → «Open with Live Server»;
- **або в терміналі:** `npx serve .` і відкрити адресу, яку він покаже.

Файл `serve.json` потрібен лише для `npx serve`: він вимикає «чисті» адреси, інакше губиться `?id=` у посиланнях. Vercel його ігнорує.

## Структура

```
index.html      головна
rubric.html     сторінка рубрики        rubric.html?id=kino
article.html    сторінка матеріалу      article.html?id=zolochivskyi-zamok
author.html     сторінка автора         author.html?id=alina-pavliuk
events.html     афіша «Що відвідати»    events.html?zhanr=Опера
about.html      про нас, команда, форма «Запропонувати тему»
search.html     пошук                   search.html?q=замок
404.html        сторінку не знайдено
css/style.css   усі стилі; кольори, шрифти й відступи — змінні на початку файлу
js/data.js      УСІ ДАНІ САЙТУ
js/main.js      шапка, футер, меню (однакові на всіх сторінках)
js/*.js         логіка окремих сторінок і пошуку
assets/photos/  фото (JPG, до 1600 px по довшій стороні)
assets/video/   відео (MP4 H.264, до 50 МБ) і постери до них
assets/logo.svg логотип; assets/og-cover.jpg — картинка для месенджерів
```

## Як додати контент (усе в `js/data.js`)

1. **Матеріал** — скопіюй будь-який об’єкт у масиві `articles` і зміни поля: `id` латиницею через дефіси, `rubric`, `subtopic` (дослівно з `subtopics` рубрики), `author` (id автора), дата `"2026-11-08"`. Текст пиши блоками в `body`: `p`, `h2`, `quote`, `gallery`, `video`, `link`. Головний матеріал на головній має `featured: true`, і такий матеріал має бути лише один.
2. **Автор** — новий об’єкт у `authors` (`id`, `name`, `role`, `bio`, `photo`). Його `id` потім вписуєш у поле `author` матеріалу.
3. **Подія** — новий рядок у `events`: `title`, `date`, `time`, `place`, `genres: ["Опера"]`, `description`. Минулі покази зникають з афіші самі.
4. **Рубрика** — один рядок у `rubrics`. Меню, футер і сторінка рубрики підхоплять її автоматично.
5. **Фото** — поклади JPG у `assets/photos/` (бажано до 1600 px, латинська назва без пробілів) і впиши шлях у `cover.src` або в `items` галереї. Обов’язково заповни `alt` (що на фото); джерело пиши в `caption`. Поки `src` порожній, на сайті показується кольорова заглушка «Фото».
6. **Відео** — або YouTube: `video: { youtubeId: "abc123" }`, або власний файл: поклади `.mp4` (H.264, до 50 МБ) у `assets/video/` і впиши `video: { src: "assets/video/назва.mp4", poster: "assets/video/назва-poster.jpg" }`. Для вертикального відео додай `ratio: "9x16"`, для квадратного — `"1x1"`.
7. **Посилання в тексті** — до абзацу додай `links`: `{ type: "p", text: "…у статті «Назва»…", links: [{ text: "«Назва»", href: "https://…" }] }`. `text` посилання — дослівна фраза з цього абзацу.

## Обмеження GitHub

- Жоден файл не повинен перевищувати 100 МБ, а для сайту краще тримати до 50 МБ. Git LFS не використовуємо.
- Велике відео стискай перед додаванням, наприклад так:
  `ffmpeg -i вхід.mov -vf "scale='if(gt(iw,ih),min(1280,iw),-2)':'if(gt(iw,ih),-2,min(1280,ih))'" -c:v libx264 -crf 28 -preset veryfast -c:a aac -b:a 128k -movflags +faststart assets/video/назва.mp4`
- Вихідні матеріали редакції (папки «Сайт ЖРН-34с…» з документами й оригіналами відео) і `js/data.backup.js` додані в `.gitignore` і на GitHub не потрапляють.

## Що ще варто знати

- Форма «Запропонувати тему» нікуди не надсилає дані (бекенду немає): після надсилання показується «Дякуємо!».
- Посилань на соцмережі й email на сайті немає. Місця для них позначені коментарем `<!-- СОЦМЕРЕЖІ — додати пізніше -->` у шапці й футері (`js/main.js`).
- Рубрика «Експерименти» тимчасово прихована: щоб повернути, розкоментуй її рядок у `rubrics` у `js/data.js`.
- Якщо зміниться домен сайту, заміни адресу в `og:image` у `<head>` кожної сторінки.
